# MIT Media Lab - Gemini API Presentations

This directory contains materials from Gemini API presentations at MIT Media Lab.

## Overview

MIT Media Lab is a research laboratory at the Massachusetts Institute of Technology, known for its unconventional research and emphasis on interdisciplinary work. This collection includes presentations, demos, and code examples shared during Gemini API talks and workshops at MIT Media Lab.

## Getting Started

To run the code examples:

1. Clone this repository
2. Navigate to the specific example directory
3. Follow the setup instructions in the example's README
4. Obtain a Gemini API key from [Google AI Studio](https://aistudio.google.com/app/apikey)
5. Run the example
