# Presentation Slides

This directory contains slides and presentation materials from MIT Media Lab talks about the Gemini API.

## Organization

Slides are organized by date and topic:

```
slides/
├── 2024-01-example-presentation/
│   ├── slides.pdf
│   └── README.md
└── 2024-02-workshop/
    ├── slides.pptx
    └── README.md
```

## File Formats

Accepted formats for slides:
- PDF (`.pdf`) - preferred for distribution
- PowerPoint (`.pptx`)
- Google Slides (link in README)
- Keynote (`.key`)

## Adding New Slides

When adding presentation materials:

1. Create a subdirectory with format: `YYYY-MM-topic-name`
2. Add your slide files
3. Include a README.md with:
   - Presentation title
   - Date and event
   - Presenter(s)
   - Brief description
   - Links to related code examples
4. If slides are in Google Slides, include the link in the README

## Viewing Online

For presentations available online:
- Add links in the main [MIT Media Lab README](../README.md)
- Include speaker notes if available
