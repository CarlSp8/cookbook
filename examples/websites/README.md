# Website Examples

This directory contains simple HTML website templates created for demonstration purposes.

## Available Websites

### 1. GitHub Website (`github.html`)
A sample landing page inspired by GitHub's design, featuring:
- GitHub-style branding and colors
- Responsive navigation header
- Hero section with call-to-action
- Feature cards showcasing GitHub's main features
- Clean, modern design

### 2. Microsoft Website (`microsoft.html`)
A sample landing page inspired by Microsoft's design, featuring:
- Microsoft logo with the iconic four-color squares
- Professional corporate styling
- Product and service showcase
- Responsive grid layout
- Microsoft's signature blue color scheme

## How to Use

Simply open the HTML files in your web browser to view the websites. These are static HTML pages that don't require any server or additional setup.

### Opening the files:
1. Navigate to this directory
2. Double-click on the HTML file (e.g., `github.html` or `microsoft.html`)
3. Or open them directly in your browser using File > Open

## Purpose

These examples demonstrate:
- Clean, modern web design principles
- Responsive layout techniques using CSS Grid and Flexbox
- Professional color schemes and typography
- Semantic HTML structure
