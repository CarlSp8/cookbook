## 2024-05-03 - Gradio External Links and Implicit Submissions
**Learning:** Gradio web apps wrap external links embedded in `gr.HTML` components in an iframe or internal routing. Navigating via these links without `target="_blank"` can trap users or reset the application state. Furthermore, explicit `aria-label`s describing the "opens in a new tab" behavior are necessary for screen reader accessibility. Additionally, when using `.submit()` events on Gradio Textbox elements to transition states, users lack visual affordance that pressing "Enter" will trigger an action.
**Action:** Always add `target="_blank"` and `rel="noopener noreferrer"` to anchor tags in `gr.HTML` Gradio elements. Additionally, include a descriptive `aria-label` (e.g., `aria-label="... (opens in a new tab)"`). Always add an `info="Press Enter to submit"` parameter to `gr.Textbox` components that rely on implicit keyboard submission, provided there is a validated `.submit()` listener attached.
