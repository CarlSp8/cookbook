## 2026-02-12 - [Gradio WebRTC Branding]
**Learning:** Default WebRTC components in Gradio lack visual identity. Using `fastrtc` allows for critical branding customizations (`icon`, `pulse_color`) that align the UI with the Gemini product identity.
**Action:** Always check for and apply `icon` (Gemini sparkle) and `pulse_color` (Gemini blue) when using WebRTC components for Gemini demos.
