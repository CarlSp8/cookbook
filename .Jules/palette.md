## 2024-05-24 - Prevent Destructive Navigation in Gradio WebRTC Apps
**Learning:** In Gradio applications that establish stateful connections (like WebRTC audio streams), standard anchor tags in `gr.HTML` without `target="_blank"` are uniquely destructive. Navigating away instantly kills the active voice session and requires the user to re-establish permissions and connections upon returning. Additionally, the default `gr.HTML` layout structure is changing in Gradio 6.0 (dropping default padding), which will break visual hierarchies if not explicitly defined.
**Action:** Always enforce `target="_blank"` and `rel="noopener noreferrer"` for external links in Gradio interfaces to protect the session state. Always explicitly set `padding=True` on `gr.HTML` components to ensure cross-version visual consistency. Furthermore, always use descriptive link text (avoiding "here") with `aria-label` to ensure screen-reader accessibility for tab-opening links.
