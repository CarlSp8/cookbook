## 2025-05-15 - [Visual Branding in WebRTC]
**Learning:** Adding a custom icon and pulse color to `fastrtc.WebRTC` transforms a generic audio interface into a branded experience. The `fastrtc` library supports this out of the box.
**Action:** Always check for `icon` and `pulse_color` props when using `fastrtc.WebRTC` to match the application theme.
