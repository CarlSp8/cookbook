# Palette's Journal

## 2025-05-15 - FastRTC UX Customization
**Learning:** `fastrtc` components (like `WebRTC`) offer rich customization options (`icon`, `pulse_color`, `icon_button_color`) that significantly enhance the visual identity of the application compared to default `gradio-webrtc` components.
**Action:** When migrating to `fastrtc`, always leverage these customization options to align with the brand identity (e.g., using Gemini sparkle icon and blue pulse color).
