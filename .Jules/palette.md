## 2025-04-29 - Gradio External Link Accessibility & State Management
**Learning:** In Gradio applications, external links within `gr.HTML` components open in the same tab by default. This is a critical UX issue because navigating away clears the entire application state (like uploaded files or API keys). Additionally, relying on implicit submission (like pressing Enter on a `gr.Textbox` mapped to `.submit()`) is not immediately obvious to users without explicit instruction.
**Action:** Always use `target="_blank"` and `rel="noopener noreferrer"` for external links in Gradio, accompanied by an `aria-label` to inform screen readers of the new tab behavior. Always use the `info` parameter on `gr.Textbox` to provide explicit interaction instructions when relying on `.submit()`.
